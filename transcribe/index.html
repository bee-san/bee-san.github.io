bee-san.github.io / transcribe

Video Transcriber

Drop in a video or audio file and get a transcript with timestamps. Speech recognition runs right here in your browser using OpenAI's Whisper.

Your file never leaves this device. The only downloads are the speech model and its code.

Drop a video or audio file

Anywhere on this page works. MP4, MOV, WebM, MP3, M4A, WAV and more.

Transcript

The model downloads once, then your browser caches it for next time.

Got a YouTube link?

A static page can't fetch YouTube videos (browsers block it), and we don't send links through anyone else's server. Download it first, then drop the file here. With yt-dlp:

yt-dlp -x --audio-format mp3 <url>
Whisper via transformers.js. Works best in recent Chrome, Edge or Firefox; very long files need lots of memory.
